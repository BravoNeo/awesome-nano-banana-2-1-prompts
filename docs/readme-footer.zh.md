## 分享你的作品

欢迎通过 [投稿 Issue](https://github.com/BravoNeo/awesome-nano-banana-2-1-prompts/issues/new)，附完整原始提示词、作者、准确原帖、模型名称和对应输出。若用到参考图片，请与输出分开标明。
