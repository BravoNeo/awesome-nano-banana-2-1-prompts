## 如何使用

1. 选择一个案例，展开完整原始提示词。
2. 替换地点、主体等变量；编辑类作品先准备自己有权使用的参考图。
3. 在支持该模型的工具中选择模型并粘贴提示词，再按你的目标调整构图、文字或风格。
