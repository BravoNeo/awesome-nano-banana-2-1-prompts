## About Nano Banana 2.1

[Nano Banana 2.1](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1?hl=en) is Google’s image generation and conversational editing model. It supports text-led creation and image references, with improvements to visual quality, character consistency and text rendering.
